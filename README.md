# 📊 VarejoMax Distribuidora — Análise de Vendas com Power BI

## Sobre o projeto

Este projeto foi desenvolvido como parte do **Desafio 01 — VarejoMax Distribuidora**, da EducaDados.

O objetivo é analisar o desempenho comercial de uma distribuidora fictícia, utilizando dados de vendas para acompanhar indicadores de faturamento, desempenho por filial, vendedores, canais de venda e evolução mensal.

O projeto faz parte do meu processo de aprendizado e da construção do meu portfólio em Análise de Dados e Business Intelligence.

## 🎯 Objetivos da análise

- Identificar as filiais com maior participação no faturamento;
- Analisar o desempenho dos vendedores;
- Comparar os canais de venda;
- Calcular o ticket médio;
- Avaliar a evolução do faturamento ao longo do tempo;
- Transformar dados em informações úteis para a tomada de decisão.

## 🛠️ Ferramentas utilizadas

- **Power BI Desktop:** criação do dashboard;
- **DAX:** criação de medidas e indicadores;
- **Modelagem de dados:** organização das tabelas e relacionamentos;
- **Visualização de dados:** apresentação dos resultados.

## 📌 Indicadores analisados

- Faturamento;
- Quantidade de vendas concluídas;
- Ticket médio;
- Participação por filial;
- Participação por canal;
- Faturamento por vendedor;
- Evolução mensal do faturamento.

Para o cálculo do faturamento, foram consideradas somente as vendas com status **Concluída**. Vendas canceladas e devolvidas foram excluídas do indicador.

## 🔎 Principais resultados

- A Loja Centro apresentou a maior participação no faturamento, com aproximadamente 30,7%;
- A Loja Norte representou aproximadamente 25,1% do faturamento;
- O canal Loja Física concentrou a maior participação nas vendas;
- Diego Almeida apresentou o maior faturamento entre os vendedores;
- O ticket médio geral foi de aproximadamente R$ 2.052,39.

Os resultados são referentes à base utilizada no desafio e não representam dados reais de uma empresa.

## 📚 Aprendizados

Durante o desenvolvimento, pratiquei:

- Construção de medidas DAX;
- Uso de `CALCULATE` para modificar o contexto de filtro;
- Cálculo de ticket médio e participação percentual;
- Organização de dados em um modelo para análise;
- Criação de indicadores e visuais no Power BI;
- Interpretação de resultados sob a perspectiva do negócio.
